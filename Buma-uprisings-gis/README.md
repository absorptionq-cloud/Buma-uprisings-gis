# 1979 부마민주항쟁 부산지역 GIS 데이터셋

1979년 10월 16일~17일 부산지역에서 전개된 부마민주항쟁의 시위·연행·경찰 진압 상황을 GIS로 재구성한 데이터셋입니다. 「부마민주항쟁 진상조사보고서」 및 관련 자료를 바탕으로 위치 정보를 디지타이징하여 구축했습니다.

본 데이터셋은 아래 논문의 분석 근거자료로 사용되었습니다. 논문에 수록된 그림지도와 애니메이션은 이 저장소의 원자료(CSV)를 QGIS로 시각화하여 제작한 결과물입니다.

권혁은 (2026). [GIS 기반 부마항쟁 초기 부산지역 시위양상과 경찰 진압 작전 분석]. [역사비평], [권(호)], [페이지].

논문의 분석 과정을 검증하거나, 동일한 시기·지역의 후속 연구에 원자료를 재사용하고자 하는 연구자를 위해 데이터·시각화 결과물·QGIS 프로젝트 파일을 함께 공개합니다.

## 데이터 설명

### 좌표계
모든 위치 데이터는 **EPSG:3857 (WGS 84 / Pseudo-Mercator)** 좌표계를 사용합니다.

### 파일별 컬럼 설명

**`*_arrested.csv` (연행자 포인트)**
| 컬럼명 | 설명 |
|---|---|
| id | 고유 식별자 |
| start time / end time | 사건 발생 시작/종료 시각 |
| place | 장소명 |
| number of people | 연행 인원 수 |
| x, y | 좌표 |
| location_accuracy | 위치 추정 신뢰도 |

**`*_point.csv` (시위 포인트)**
| 컬럼명 | 설명 |
|---|---|
| id | 고유 식별자 |
| place | 장소명 |
| time | 발생 시각 |
| content | 사건 내용 |
| size / weight | 규모(인원수 등) |
| x, y | 좌표 |
| location_accuracy | 위치 추정 신뢰도 |

**`*_line.csv` (시위 라인)**
| 컬럼명 | 설명 |
|---|---|
| route_id | 경로 고유 식별자 |
| start_time / end_time | 이동 시작/종료 시각 |
| content | 이동 내용 |
| route_confidence(route confidency) | 경로 추정 신뢰도 |
| time_confidence(time confidency) | 시각 추정 신뢰도 |

**`*_police.csv` (경찰 포인트)**
| 컬럼명 | 설명 |
|---|---|
| no / id | 고유 식별자 |
| place | 장소명 |
| time | 발생 시각 |
| content | 진압 내용 |
| num_arrested | 해당 지점 연행 인원 |
| unit_name | 투입 경찰 부대명 |
| suppression_type | 진압 유형 |
| x, y | 좌표 |
| location_accuracy | 위치 추정 신뢰도 |

> **신뢰도(confidence/accuracy) 값의 판정 기준**은 원 연구(논문)의 기준표를 따릅니다. 세부 등급 기준은 첨부 논문/보고서를 참고해주세요.

## 동영상 (videos/)

논문에서 활용한, 그림지도를 시계열로 이어붙여 시위 전개과정을 시각화한 애니메이션 2개(1979-10-16, 1979-10-17)가 포함되어 있습니다.

## QGIS 프로젝트 (qgis_project/)

`.qgz` 프로젝트 파일에는 위 CSV를 기반으로 한 벡터 레이어와 스타일링이 포함되어 있습니다.

**베이스맵 관련 안내**: 본 프로젝트는 원래 국토정보플랫폼(map.ngii.go.kr)에서 제공하는 1970~1980년대 1:5000 종이지도를 지오레퍼런싱하여 베이스맵으로 사용했습니다. 해당 지도는 저작권 문제로 본 저장소에는 **포함하지 않았습니다**. 프로젝트를 완전히 재현하시려면:
1. 국토정보플랫폼에서 해당 연도·지역의 종이지도를 별도로 내려받고
2. QGIS의 Georeferencer 도구로 EPSG:3857 기준 지오레퍼런싱한 뒤
3. 프로젝트에 레이어로 추가해주세요.

베이스맵 없이 바로 시각화를 확인하시려면 QGIS의 XYZ Tiles(OpenStreetMap 등)를 대신 추가하여 사용하실 수 있습니다. 다만 현재 지형·도로망은 1979년 당시와 다를 수 있습니다.
